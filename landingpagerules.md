# O Primo Digital — Landing Page Premium (Noir Comic Edition)

## Objetivo

Crie uma landing page extremamente premium para uma empresa chamada **O Primo Digital**, especializada em:

- Desenvolvimento de Sites
- Landing Pages
- Aplicações Web
- Sistemas Personalizados
- Automação de Processos
- Estratégia Digital

O objetivo da página é transmitir imediatamente que esta não é uma agência comum, mas uma empresa de tecnologia especializada em criar soluções digitais modernas para empresas.

Toda a página deve ter foco absoluto em conversão.

---

# Direção de Arte

A estética da landing page deve ser inspirada no universo noir dos quadrinhos.

Principal referência artística:

**Max Payne 1 e Max Payne 2**

Inspirar-se em:

- ilustrações preto e branco
- alto contraste
- sombras profundas
- texturas de HQ
- efeito de tinta
- halftone
- atmosfera cinematográfica
- composição dramática
- visual elegante e tecnológico

IMPORTANTE:

Não utilizar aparência de videogame.

Não utilizar aparência "gamer".

O objetivo é transmitir sofisticação.

A referência é apenas a direção artística.

Misturar essa estética com interfaces modernas como:

- Stripe
- Vercel
- Linear
- Framer
- Apple

Resultado esperado:

Uma mistura entre

"Graphic Novel"

+

"Empresa SaaS Premium"

# Experiência do Usuário

A landing deve causar a sensação de estar navegando por um site de uma empresa de tecnologia internacional, mas com uma identidade visual única inspirada em graphic novels noir.

Cada seção deve parecer cuidadosamente dirigida, com ritmo visual, contraste, hierarquia e microanimações que reforcem a percepção de qualidade.

## Regra mais importante

**A identidade da marca deve ser "Noir Tech".**

Imagine que **Max Payne**, **Apple**, **Vercel** e **Stripe** colaboraram para criar a landing page de uma empresa de tecnologia premium. O resultado deve ser elegante, minimalista, cinematográfico e altamente profissional, usando o preto e branco como linguagem principal e o laranja apenas como um acento de interação e destaque.
